# Security policy

The current main branch and latest release receive fixes. To report a vulnerability,
use the repository Security tab → Report a vulnerability (when private reporting is
available); otherwise open an issue with minimal, non-sensitive details requesting
private coordination. Do not publish private notification text, credentials or exploits
against another user's device. Never send signing keys.

This app has no server or telemetry. Notification access and overlay permission are
explicit Android grants and can be revoked in system settings. Content is transient
in memory. Android system/OEM restrictions must not be bypassed.
